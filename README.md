
# Exportaciones-argentinas2021/2025
Evolución de las exportaciones argentinas (2021-2025)

En este proyecto trabajé sobre la evolución de las exportaciones argentinas durante los últimos cinco años, desde 2021 hasta 2025. El objetivo fue observar cómo fueron cambiando los valores de las exportaciones durante este período y analizar las principales variaciones que se produjeron.

Para realizar el trabajo utilicé información de archivos de Excel y Word. En los Excel organicé los datos de las exportaciones y algunos de sus principales rubros. También trabajé con un documento de Word relacionado con la información y la normativa vinculada al tema.

A partir de toda esta información realicé un análisis de la evolución de las exportaciones y lo llevé a una página web para presentar los datos de una manera más clara, ordenada y visual.

Para desarrollar el proyecto utilicé diferentes herramientas. Utilicé Perplexity para buscar información y fuentes relacionadas con las exportaciones argentinas y la normativa. Utilicé Gemini para analizar la información de los archivos y para generar la página web. Luego utilicé Netlify para publicar la página y poder acceder a ella mediante un enlace, y GitHub para guardar y presentar el proyecto.

El período analizado comprende los años 2021, 2022, 2023, 2024 y 2025. En la página se pueden observar los valores de exportación de cada año, sus variaciones y un gráfico que permite comparar los distintos períodos. También se incluye información sobre los principales rubros de exportación y algunos cambios relacionados con la normativa argentina.

Las principales fuentes utilizadas fueron el INDEC, el Boletín Oficial de la República Argentina, Argentina.gob.ar y Cancillería Argentina.

La página web fue publicada mediante Netlify y se puede acceder desde el siguiente enlace:

https://proyecto-exportaciones-argentinas.netlify.app

Este trabajo me permitió conocer un poco más sobre cómo fueron evolucionando las exportaciones argentinas en los últimos años y aprender a organizar información de distintas fuentes para después presentarla de una forma más visual mediante una página web.
